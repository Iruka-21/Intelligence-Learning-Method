## 1. このプロジェクトについて

ILMは、学習対象の性質と学習者の現在地を確認し、適切な学習方法・順序・評価方法を選択するための汎用フレームワークです。学校の教科だけでなく、言語、研究、プログラミング、専門職、生活技能、身体技能、芸術、対人能力などを扱うことを目指します。

目的は、長時間学習すること自体ではありません。限られた時間・教材・環境の中で、必要な知識や技能を獲得し、実際に使える状態にし、必要な期間維持・発展させることです。

ILMの「Intelligence」は、情報の収集・選別、情報源の評価、複数の説明の比較、不確実性の明示といった情報分析の考え方を指します。諜報機関の訓練が学力向上を直接証明するという意味ではありません。情報分析技法は、研究・史料分析・仮説比較など、適合する課題に限定して転用します。

## 3. この本の使い方

最初からすべてのマップや技法を覚える必要はありません。まずは次の手順で一つの学習目標を試してください。

1. **目標を決める。** 「勉強する」ではなく「何ができれば達成か」を行動で書く。
2. **能力を分解する。** 必要な知識・理解・手順・判断・実践・表現などを洗い出す。
3. **現在地を診断する。** 短い問題、説明、実技、作品など、対象に合った方法で確認する。
4. **前提と安全条件を確認する。** 必須前提が不足していればBridge Learningで必要部分を補う。
5. **学習順序を選ぶ。** 単純→複雑、全体→部分、全体→部分→全体、並行学習から選択する。
6. **技法を選ぶ。** 中心技法を一つ決め、補助技法は必要なものだけ追加する。
7. **実際に使う。** 解く、説明する、作る、演じる、実験するなど、目標に対応した実践を行う。
8. **独立して検証する。** 教材やヒントに頼らず、到達基準を満たせるか確かめる。
9. **弱点を補修する。** 誤りの原因に対応する学習へ戻り、必要な復習を設定する。
10. **PDCAで改善する。** 学習結果と時間・負担を確認し、次の計画を修正する。

## 4. 学習の順序は一律にしない

ILMは「簡単な内容から始める」「難しい内容から始める」のどちらも固定ルールにしません。次の条件を見て選びます。

| ルート | 順序 | 選択しやすい条件 |
|---|---|---|
| A. 単純→複雑 | 前提・部品 → 小課題 → 組合せ → 全体 | 初学者、必須前提不足、要素間の相互作用が強い、安全上の失敗コストが高い |
| B. 複雑・全体→部分 | 全体像・代表課題 → 構造分解 → 弱点練習 → 全体 | 既有知識がある、全体の文脈が重要、統合技能の目標が明確 |
| C. 全体→部分→全体 | 全体を体験 → 部分を分解 → 部分練習 → 全体課題 | 創作、研究、スポーツ、複雑な実践・プロジェクト |
| D. 並行学習 | 独立した要素を同時に学ぶ | 要素間の依存が小さく、並行する方が効率的 |

必須の前提が欠けている場合は、必要最小限のBridge Learningを先に行います。推奨前提は課題に応じて省略・並行できます。安全・資格・監督要件は、自己判断だけで解除しません。

**学ぶ内容の順序**と**一日の作業順序**は別々に決めます。一日の作業順序は、重要度、期限、集中状態、着手抵抗、切替コスト、疲労、安全性などで判断します。

## 5. 前提知識とBridge Learning

ILMは、高校・大学レベルの先行学習や専門知識を標準利用の条件にしません。標準入口は、義務教育修了相当の機能的な読み書き、基礎計算、図表の読み取り、基本的な指示理解を想定します。これは学校歴や卒業証明を求める条件ではありません。

標準入口の基礎が十分でない場合も、学習参加を排除しません。対象課題に必要な部分を次のように補います。

1. 本課題で必要な前提を特定する。
2. 必須・推奨・並行可能な前提に分ける。
3. 必須前提の不足だけを確認する。
4. 必要最小限の教材・例・練習で補う。
5. 短いゲート課題で確認する。
6. 合格した部分から本課題へ接続する。
7. 本課題で不足が再発した場合は、該当部分に戻る。

## 6. 技法の選び方

学習技法は、知名度や「スパイ式」「大学式」といった名称ではなく、学習目標と課題の性質によって選びます。

| 学習目的 | 主な候補 | 確認方法 |
|---|---|---|
| 覚える | 想起練習、分散学習 | 教材を閉じて再現する |
| 理解する | 自己説明、具体例、図解 | 理由・仕組みを説明する |
| 手順を身につける | 例題、部分完成、独立演習 | 自力で手順を再現する |
| 方法を選ぶ | 問題比較、交互演習 | 選択理由を説明する |
| 根拠を分析する | 情報源評価、複数仮説、反証 | 証拠と推論を区別する |
| 身体技能を身につける | 指導下の実技、部分練習、フィードバック | 安全な条件で実技評価する |
| 創作する | 制作、試作、批評、改稿 | 作品と評価基準で確認する |
| 伝える | 説明、発表、対話 | 質問への応答・再構成を確認する |

一度に多くの技法を詰め込まず、中心技法を一つ、補助技法を必要に応じて追加します。

## 7. RAP・PDCA・復習

- **RAP（Rapid Acquisition Protocol）**：目標定義、必要情報の選別、集中的な学習、実践、検証、弱点補修を行う短期習得プロトコルです。
- **PDCA**：Plan（計画）、Do（実行）、Check（評価）、Act（改善）で、学習計画全体を見直します。
- **復習**：弱点を優先しながら、習得済みの知識・技能も保持目標に応じて一部確認します。
- **確率モデル**：BKT等は反復可能な知識項目の推定候補です。すべての技能に適用せず、データで校正されていない確率は表示しません。

「20%短縮」「7分で必ず打ち切る」などは普遍的な規則ではありません。課題の目的、正確性、安全、時間制約、学習者の状態に応じて判断します。

## 8. 一冊のノートで運用する

ILMはスマートフォンのカレンダーや学習管理アプリを必須にしません。現役ノート一冊に、目標、分野索引、能力マップ、学習記録、復習予定、エラー、習得証拠、PDCAをまとめます。

ノートを使い終えたら番号を付けて保管し、新しいノートには未完了の目標と索引を引き継ぎます。専門資料・教科書・作品・研究記録などは別途保管して構いません。マスターノートは学習の運用・参照に使います。

## 9. 科学的根拠と限界

本書は、既存研究・教育機関の学習支援資料・情報分析資料を参照して構成した設計体系です。個別技法の研究結果と、ILM全体の効果は区別します。

- 想起練習・分散学習などは複数の研究で支持されていますが、効果は課題・学習者・フィードバック・保持期間などで変わります。
- 情報分析の構造化技法は、情報評価や仮説比較に適する課題に限定して使います。諜報分析資料は、学力向上を直接証明するものではありません。
- 身体・医療・専門職などでは、必要な安全・資格・設備・指導者・監督条件を優先します。
- ILM全体が全分野で有効であることは、まだ大規模比較試験で実証されていません。
- 小規模な個人試行は本人にとっての参考であり、他者にも同じ効果がある証明ではありません。

効果を検証する場合は、通常学習、研究支持技法を用いる学習、ILMの統合手順を比較し、学習時間、直後の成績、遅延保持、初見課題への転移、負担を記録します。結果が良くない場合も報告します。
